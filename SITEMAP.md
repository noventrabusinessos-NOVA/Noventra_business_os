# 5. USER JOURNEY

1. User visits the public homepage.
2. User learns about NOVENTRA.
3. User creates an account.
4. User enters the dashboard.
5. User creates a business project.
6. User completes the business idea form.
7. User reviews AI-generated analysis.
8. User develops the business model.
9. User creates a brand identity.
10. User generates a website draft.
11. User creates a marketing plan.
12. User saves and manages the project.

# 6. NAVIGATION PRINCIPLES

- Simple and predictable navigation.
- Consistent page structure.
- Clear visual hierarchy.
- Responsive design.
- Accessible controls.
- Contextual navigation between related modules.
- Clear separation between public and authenticated areas.
